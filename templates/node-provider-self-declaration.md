### (B) Statement of Provision of Node Machines

We hereby guarantee that we shall provide node machines in accordance with the
required Hardware Configuration for running the ICP Network, as described on the
ICP wiki (see
[Node Provider Machine Hardware Guide](https://internetcomputer.org/wiki/node-hardware-guide/)).

### (C) Statement of Good Intent

- We guarantee to the world that we shall honestly operate the node machines we
  provide, and that should we behave dishonestly, for example by deliberately
  interfering with our node machine(s) to prevent them correctly processing ICP
  protocol messages, in collusion with others or alone, that we will be liable to
  users of the network, and to other node providers, for any damages caused.
- We further declare we are aware that any deliberate interference with a node
  machine, which causes it to incorrectly process ICP protocol messages,
  represents a misuse of that hardware, and of any hardware it interacts with,
  and that in some jurisdictions, that may constitute a crime.
