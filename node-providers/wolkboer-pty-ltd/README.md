## Known discrepancy with the NNS proposal

Proposal [124485](https://dashboard.internetcomputer.org/proposal/124485) references
the self-declaration as `Self-declaration-Wolkboer.pdf` with SHA-256
`63df7581098e...`. The wiki hosted only a PNG of that declaration by the time of
the backfill, and that PNG is the file above. Its content is the declaration the
proposal refers to — dated 2023-08-30 and signed by Pieter Boer for
WOLKBOER (Pty) Ltd — but being a different file format it does not reproduce the
SHA-256 in the proposal.

The proof of identity in this directory does match the proposal exactly.
